# 🎓 Doctor of Engineering in AI/ML – Lectures & Assignments

Welcome to my curated GitHub repository for all coursework, assignments, and personal notes from my Doctor of Engineering program in Artificial Intelligence & Machine Learning at George Washington University. This space is both a study hub and a growing archive of practical, hands-on applications in data engineering, machine learning, and AI systems design.

---

## 📚 Contents

This repository is organized by course and topic for easy navigation:

### ✅ Core Courses

- `SEAS8515_Data_Engineering_for_AI/`
  - Lecture notes with expanded study guides
  - Jupyter notebooks for Spark, Delta Lake, DAGs, CDC, SQL ops, and ingestion pipelines
  - Midterm study sheets and exam prep

- `SEAS8510_Machine_Learning_Foundations/`
  - Lecture content covering supervised/unsupervised learning
  - Homework notebooks: feature engineering, model selection, evaluation metrics
  - Projects on imbalanced data, interpretability, and ensemble methods

- `SEAS8520_AI_Ethics_and_Society/`
  - Weekly readings with reflection summaries
  - Debate writeups and policy analysis on algorithmic fairness, transparency, and social impact
  - Case studies

### 🤖 Dissertation Research

- `Dissertation/`
  - Research proposal: *"Emotionally Intelligent AI Tutors for Early Education"*
  - Literature review and concept models using Affectiva, Azure Emotion API
  - Code prototypes for emotion recognition and adaptive interaction logic
